# 國小折線圖教材包：課綱、核心目標與學習內容整理

2026-11-14 整理。資料來源：Codex 與 Gemini 各自上網查證，Claude 統整。課綱條文都已和教育部《十二年國民基本教育課程綱要 國民中小學暨普通型高級中等學校—數學領域》（107 年 6 月，108 學年度起實施）原文 PDF 逐字核對；標「未核對」的地方，請老師查原文後再用。

---

## 一、一句話結論

- **四年級報讀，五年級製作，六年級比較各種統計圖。**
  - 四年級（D-4-1）：讀懂折線圖，並和長條圖比較。
  - 五年級（D-5-1）：自己畫折線圖，並知道什麼時候該用折線圖。
  - 六年級（D-6-1）：學圓形圖時，回頭比較長條圖、折線圖、圓形圖各自的使用時機。
- 教材包可以分成兩條主線：「讀圖」（對應四年級）和「畫圖」（對應五年級）。前面再加先備能力診斷：表格、刻度、數線。

## 三、學習表現（課綱原文，已核對）

| 階段 | 代碼 | 原文 |
|---|---|---|
| 第一階段（1–2 年級） | d-I-1 | 認識分類的模式，能主動蒐集資料、分類，並做簡單的呈現與說明。 |
| **第二階段（3–4 年級）** | **d-II-1** | **報讀與製作一維表格、二維表格與長條圖，報讀折線圖，並據以做簡單推論。** |
| **第三階段（5–6 年級）** | **d-III-1** | **報讀圓形圖，製作折線圖與圓形圖，並據以做簡單推論。** |

學習表現都有「並據以做簡單推論」。所以評量不能只看點畫對沒有，也要讓學生說出：從圖上看到什麼、根據哪一點。

## 五、先備與延伸（教材包的前後順序）

| 位置 | 代碼 | 和折線圖的關係 |
|---|---|---|
| 表格 | D-3-1 | 畫圖前資料要先整理成表格 |
| 尺與刻度 | N-2-11 長度、S-2-3 直尺操作 | 「一樣的間隔代表一樣多」 |
| 數線 | **N-3-11 整數數線：認識數線，含報讀與標示。連結數序、長度、尺的經驗，理解在數線上做比較、加、減的意義。數線須從 0 開始。** | 折線圖的兩條軸都是數線（已核對） |
| 小數刻度 | N-4-8 數線與分數、小數 | 溫度、身高等含小數的資料 |
| 時間 | N-3-17 時間：「日」、「時」、「分」、「秒」…… | 橫軸常用時間（已核對） |
| 長條圖 | D-4-1 | 和折線圖放在同一個條目，可以一起比較 |
| 延伸 | D-6-1、D-7-1、D-8-1（累積次數折線圖等） | 圖表選擇；國中的統計圖 |

**注意**：N-3-11 規定「數線須從 0 開始」，這是數線條目的要求，不等於所有統計圖的縱軸都要從 0 開始。國教院課程手冊（D-5-1 解說）允許必要時用波浪線省略。教材可以先從 0 開始，進階再教省略符號。

## 六、特教相關連結

- **特殊需求領域「學習策略」**：Codex 引用了以下條目並附來源，我沒有逐字核對。
  - 特學1-Ⅱ-1：察覺訊息中的重要項目。（找標題、兩軸、單位、刻度）
  - 特學1-Ⅱ-4：找出並練習標記學習內容的重點。（標記指定的點）
  - 特學1-Ⅱ-7：將學習材料化繁為簡，加深記憶。（固定的讀圖步驟卡）
  - 特學1-Ⅱ-13：透過討論或對話理解學習內容。（用句型說出理由）
  - 特學4-Ⅱ-2：發現並留意自己學習時常犯的錯誤。（自己檢查刻度、單位）
  - 特學1-Ⅲ-11：透過自問自答確認理解的程度。
- **課程調整依據**：《高級中等以下學校特殊教育課程教材教法及評量實施辦法》第 4、8、9 條。內容、歷程、環境、評量都可以依個別需求和 IEP 調整，但不應因為障礙標籤，就一律刪掉推論或畫圖目標。
- **議題融入（可選用）**：
  - 環境教育 環E8：認識天氣的溫度、雨量要素與覺察氣候的趨勢及極端氣候的現象（氣溫、雨量折線圖）
  - 生活課程 A-I-2：事物變化現象的觀察（植物成長記錄）

## 七、建議的教材包架構（設計建議，非課綱規定）

Codex 建議 8 個活動，Gemini 建議 4 個單元，兩者方向一致。我把兩邊合併，對齊面積教材的格式（單元 → 活動、七步驟、三層提示）：

| 單元 | 活動 | 學習目標 | 課綱 |
|---|---|---|---|
| 0 先備 | 0-1 表格找資料、0-2 刻度補數（一格是 1／2／5／10） | 從表格找指定資料；判斷一格代表多少 | D-3-1、N-3-11 |
| 1 認識折線圖 | 1-1 找齊圖的零件（圖名、橫軸、縱軸、單位、點） | 指出圖的各個部分，說出這張圖在記錄什麼 | D-4-1、數-E-B2 |
| 2 讀圖 | 2-1 找時間讀數值（十字導引線）、2-2 反過來：找數值對應的時間 | 由橫軸找點，再對縱軸讀數 | D-4-1、d-II-1 |
| 3 看變化 | 3-1 上升、下降、不變；3-2 哪一段增加最多（和「最高點」分開） | 比較相鄰兩點；用數字說明變化 | d-II-1、數-E-C1 |
| 4 選對圖 | 4-1 長條圖還是折線圖？（分類資料 vs 有序變化資料） | 知道什麼資料適合畫折線圖 | D-4-1 備註、D-5-1 備註 |
| 5 畫折線圖（五年級） | 5-1 表格變折線圖：描點、依序連線（點會自動吸附到交叉點）；5-2 自己訂刻度；5-3 波浪線省略（進階） | 依時間順序描點連線，標好圖名、軸名、單位 | D-5-1、d-III-1 |
| 6 小小調查 | 6-1 記錄一週資料（例如氣溫），畫圖並說明 | 用自己的資料回答問題 | D-5-1、數-E-A3、C1 |

**難度三級**（兩邊都建議）：
- 入門：3–4 個點、整數、一格是 1、縱軸從 0 開始
- 一般：5–7 個點、一格是 2、5 或 10
- 挑戰：小數、縱軸不從 0 開始（有波浪線）、兩條線比較

## 八、常見錯誤（可作為觀察代碼的候選）

| 錯誤 | 建議回饋 | 觀察代碼（暫擬） |
|---|---|---|
| 每一格都當成 1 | 標出兩個已知刻度，先算中間有幾格 | `scaleAsOne` |
| 數刻度線，而不是數間隔 | 動畫一格一格跳 | `countTicks` |
| 讀錯行（橫軸對錯時間，或縱軸對錯位置） | 十字導引線、高亮那一行 | `misalign` |
| 把最高點當成「增加最多」 | 分開問「哪天最高」和「哪兩天之間增加最多」 | `highVsChange` |
| 只看一段就說「一直上升」 | 一段一段檢查 | `partialTrend` |
| 縱軸不從 0 開始，卻從 0 數 | 顯示起點和波浪線；可切換「還原全貌」 | `ignoreBreak` |
| 線比較陡，就認定增加比較多（兩張圖刻度不同） | 先比較兩張圖的刻度 | `slopeOnly` |
| 漏畫 0，或把沒有資料當成 0 | 分清楚「量到 0」和「沒量到」 | `zeroMissing` |
| 不照時間順序連線 | 表格和橫軸同步標記 | `orderJump` |
| 把分類資料（水果種類）畫成折線圖 | 「連起來的線代表什麼？」反例 | `wrongChart` |
| 把圖上的變化當成一定會發生的未來 | 分開問「圖上看到什麼」和「你猜會怎樣」 | `overPredict` |

## 十、三方差異與我的判斷

| 項目 | Codex | Gemini | 我的判斷 |
|---|---|---|---|
| D-4-1、D-5-1、d-II-1、d-III-1、數-E-B2、C1 原文 | 正確 | 正確 | 兩方都和課綱原文一致 |
| 時間的先備條目 | N-2-14、N-3-17 | N-3-14、N-4-10 | **Gemini 錯了**：課綱裡 N-3-14 是「面積」，N-4-10 是「角度」；N-3-17 才是時間 |
| 特學條目 | 特學1-Ⅱ-1 等，附來源 | 特學1-III-1、特學2-III-2 等，無原文 | Gemini 的代碼和說明對不上原文，**不採用**；Codex 的條目採用，但未逐字核對 |
| 縱軸從 0 開始 | 區分數線規定與統計圖 | 進階教波浪線 | 一致：入門從 0 開始，挑戰級再教波浪線 |
| 架構 | 8 個活動（0–7） | 4 個單元 | 合併成第七節的 7 個單元，**請老師決定**要不要這麼多 |

### 請老師決定
1. 對象年級：只做四年級報讀，還是四、五年級都做（含畫圖）？
2. 單元數量：要第七節的完整版，還是先做「認識、讀圖、看變化、畫圖」4 個核心單元？
3. 要不要做「兩條線比較（複式折線圖）」和「波浪線省略」？課綱沒有明列，Gemini 指出部分版本五年級有教。
4. 情境資料：氣溫、身高、存錢、植物成長，用哪幾種？
5. 七步驟名稱：讀圖題和畫圖題的流程不同，要分成兩套嗎？
