## 二、統一格式（照時間小管家）

1. 每包最後一個單元，名稱「○○小幫手／小管家」，5～6 個活動，標出數學代碼＋跨領域代碼。
2. 共用「生活決策五步」：**看情境 → 找出要算什麼 → 選方法 → 算出來 → 檢查合不合理、做決定**。每包的核心活動用這五步，三層提示也照這五步給。
3. 每包加一條「生活應用版」路徑，只含這個單元，老師可直接指派。
4. 每包加一份「生活探測卷」（新情境、沒教過的題），可當類化探測，跟時間包的 time-life-probe 一樣。
5. 情境以學校、家裡、社區走得到的地方為主，數字範圍沿用各包原本的上限（例如面積邊長在九九內）。
