## 三、步驟套

### 看分數五步（單元 1、2、4）
| 步 | 名稱 | 學生要做的事 |
|---|---|---|
| 1 | 找整體 | 「1 個」是什麼？（一張餅、一條緞帶）整體外框會發亮 |
| 2 | 一樣大嗎 | 檢查每一份是不是一樣大；不一樣大就不能說幾分之一 |
| 3 | 數全部幾份 | 全部分成幾份 → 寫在下面（分母） |
| 4 | 數拿了幾份 | 塗色、拿走幾份 → 寫在上面（分子） |
| 5 | 讀出來 | 「4 分之 3」；先讀下面再讀上面 |

### 分數計算五步（單元 3、5、11）
| 步 | 名稱 | 學生要做的事 |
|---|---|---|
| 1 | 看分母 | 分母一樣嗎？一樣才能直接數（不一樣到單元 6） |
| 2 | 換成幾個 | 3/5 是 3 個 1/5 |
| 3 | 數或加減 | 用「幾個 1/5」來加、減、比 |
| 4 | 分母不變 | 答案還是「幾個 1/5」，分母不用加 |
| 5 | 檢查 | 看圖對一對；超過 1 嗎？要不要換成帶分數 |

### 一樣多四步（單元 6）
疊在一起比 → 切細（每份再分 2、3 份）→ 分母、分子乘同一個數 → 圖上檢查一樣大。

### 數線四步（單元 7）
找 0 和 1 → 0 到 1 分成幾段（數「段」不數「線」）→ 一段是幾分之一 → 數到第幾段。

### 通分五步（單元 8）
看分母一樣嗎 → 找兩個分母的公倍數（乘以 2、3、4、5 找，不直接相乘；可連到因數與倍數包）→ 擴分成同分母 → 加減 → 約成最簡分數。

### 分數乘除五步（單元 9、10）
看情境（幾個一樣多／的幾分之幾／分成幾份／一份是多少）→ 畫圖（長條或面積圖）→ 列式 → 算（能約分先約分；除法換成乘倒數）→ 檢查大小（乘以小於 1 的數會變小）。

### 生活決策五步（單元 11）
要做什麼（分給誰、做幾份）→ 整體是什麼（一個披薩、一瓶、一杯）→ 用哪一種分數算（平分、加、減、乘、除）→ 算出來 → 夠不夠、合不合理（每人一樣多嗎？量杯舀得出來嗎？）。

**提示三層**沿用（第一層提醒看哪裡 → 第二層給方法 → 第三層幾乎給答案），每步有「看老師做」示範。**分數圖卡**（圓形、長方形條）像因數包的九九乘法表一樣常駐，老師可關，記錄有沒有開。

## 六、觀察代碼（暫擬）

| 代碼 | 錯誤 | 活動 |
|---|---|---|
| `unequalOK` | 沒平分也說是幾分之一 | 0-2、1-1 |
| `numDenSwap` | 分子、分母寫反 | 1-3、2-2 |
| `partToPart` | 分母寫成「沒塗色的份數」（塗 1 格剩 3 格寫 1/3） | 2-2 |
| `bigDenBig` | 分母大就比較大（1/5 > 1/3） | 3-1 |
| `addDen` | 分母也相加（1/5＋2/5＝3/10） | 3-2、5-1 |
| `mixedConvert` | 帶分數、假分數互換錯（整數忘了乘分母） | 4-2 |
| `borrowWhole` | 帶分數減法不會把 1 換成分數 | 3-3、5-1 |
| `equivAdd` | 等值分數用加的（2/3＝3/4） | 6-2 |
| `countTicks` | 數線上數刻度線而不是段 | 7-1 |
| `fracDecDigit` | 1/5 寫成 0.5、1/4 寫成 0.4 | 7-2 |
| `wrongWhole` | 搞錯整體（兩個圓當成一個整體） | 4-1、11-1 |
| `denProduct` | 通分一律把分母相乘（可以，但不鼓勵；不算錯，記錄） | 8-2、8-3 |
| `addAcross` | 異分母直接分子加分子、分母加分母 | 8-3 |
| `notSimplest` | 答案沒有約成最簡分數 | 8、9、10 |
| `multBigger` | 以為乘法一定變大、除法一定變小 | 9-3、10-4 |
| `divFlipWrong` | 倒數倒錯邊（被除數也倒過來） | 10-4 |
| `remainderFrac` | 整數相除只寫商和餘數，不寫成分數 | 10-1 |
