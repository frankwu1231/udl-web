## 2026-10-26：第 22 版（學習小幫手「小方」，先以輕度智能障礙學生為主）

- 解題頁右下角的小機器人（`public/buddy.js`、`buddy.css`）。它不另外寫提示，而是在對的時候幫學生打開原本的三層提示和「我卡住了」。
- 卡住偵測：同一步沒有動作超過老師設定的秒數（30／60／90，預設 60），先問「要不要我幫你？」，按「好」打開第 1 層提示；再過一樣久還沒動，幫學生打開「我卡住了」。學生一直在動但一直錯時也會幫：同一個錯答案再試一次，提醒「換一個想法」；10 秒內又答錯，說「慢慢來，先看提示」；答錯 3 次打開「我卡住了」；在同一步待了 3 倍等待時間（就算一直在動）也會問要不要幫忙。答對會稱讚。看提示、看影片、朗讀、休息時不計時。小測驗只鼓勵、不給提示；老師示範時不打擾。
- 專心提醒（預設關閉）：老師開啟後，學生先看到說明並按「好」才開鏡頭。用 MediaPipe Face Landmarker 在瀏覽器裡判斷臉有沒有朝向螢幕（低頭寫字不算），轉頭或看不到臉超過 3／5／8 秒就提醒，回來時說「歡迎回來」；兩次提醒至少隔 20 秒，2 分鐘內 3 次就問要不要休息。影像不錄、不存、不上傳，畫面上一直顯示「📷 鏡頭開著」並可以關掉。模型從 jsDelivr 與 Google 下載（約 4 MB + wasm）。
- 小幫手的動作都寫進紀錄（事件「小幫手」），CSV 可以看到主動幫忙、接受提示、專心提醒的次數。
- 教師備課新增「🤖 學習小幫手」設定區；可套用到全部活動。
- 現場試用紀錄（`public/research.js`、`research.css`、`research/試用紀錄.gs`）：教師備課「📋 現場試用紀錄」貼上 Apps Script 網址與通行碼後，學生頁開始時由老師點選教師代號（T01…）與學生號碼（產生 `T01-S03`），紀錄只用代號、自動上傳到 Google 試算表（場次、操作紀錄、每題摘要、教師設定、教師觀察、學生回饋、教師回饋、技術問題），斷線時先存在本機再補傳。上方工具列可一鍵記錄老師幫忙、小方不準、分心、投入、技術問題；換學生時問 3 題，下課時老師填 5 題。家長未同意的學生不開鏡頭，鏡頭畫面不上傳。設定步驟見 `research/部署說明.md`。測試共 59 項。

## 教學流程

目前預設為「圖像引導模式」。教師工具可切換成文字引導模式；切換不會改變長方形尺寸或數學判分要求，但會從本步的新計畫開始。圖像模式使用一頁一問的選擇卡、任務圖示和可播放／暫停／逐格觀看的四格數學示範。詳細操作見 `dist/visual-guide.html`。原 `dist/guide.html` 與v2手冊描述文字流程。

圖像模式將獨立練習入口移至教師工具；評量題本不提供圖像示範或策略提示。示範是固定的SVG數學動畫，不是實拍影片，也沒有生成式AI。

第一節採「鋪一鋪、數一數、一列一列加」；第二節連到「寫成乘法、長乘寬、轉方向」。依學生理解程度增加課次，不強制每節完成所有步驟。

## v2：UDL設計與SRL循環

每個教學步驟都先選目標和方法，再操作、核對、檢查答案，最後自評、說明原因並決定下一輪方法。無論答對或答錯，都可反思後重試或換尺寸；答對並完成反思後可進入下一步。下一輪顯示上一次的調整，方法預帶入，目標仍由學生確認。

教師工具提供回應方式及SRL觀察欄位，記錄實際行為與支持程度。「自己試試」完成後，可選擇再練習的步驟，回到新的規劃循環。教師指定起點、換學習模式或按重來屬人工重新開始，不等同完成一輪反思。

教師工具內可開啟 dist/guide.html：包含15項UDL設計規準、實際檢驗方式、證據及修正欄位，可列印或下載填寫紀錄JSON。檢核表不預先判定符合；學生適用性與學習成效需實際試教。

- 方塊可點擊、拖曳或以鍵盤操作；自動吸附且每格最多一片。
- 點數時每片只保留一個計數記號；再按一次撤除。
- 累加需實際點選每列並填加數，才可前進。
- 乘法容許交換因數，但另檢查每列個數與列數。
- 無格線教學可以要求顯示格線，記為支持。
- 旋轉保留圖形比例與單位格大小。
- 教師工具可改4×2、3×2、3×3、5×2，並指定教學起點。

## 評量與紀錄

「自己試試」提供A、B、C三份5題課堂檢核。作答中沒有策略提示或對錯回饋；完成後才顯示結果。不強制10分鐘截止，保存實際耗時。與原紙本不同的數字輸入、加法空格及朗讀條件應於研究前固定，不能混用成績。

教師可下載本次CSV；紀錄僅在頁面記憶體，重整或關閉後消失，不上傳伺服器、不收姓名。核對發現與答案快照只代表操作與自述，是否自主、是否真的核對，由教師觀察另記。三份題本未校準等值，網站不宣稱正式測量效度或自動判定精熟。
